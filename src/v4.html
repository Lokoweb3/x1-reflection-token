v4: holder passes

The vault program splits the holders’ share itself. Each holder registers a pass once; every round, the program reads each pass’s live balance and divides the waiting XNT by it. There’s no off-chain list, no IPFS file and no publisher key, and anyone can run a round.

How to try it

  1. Launch a token as usual. On this site, new tokens get a v4 vault.
  2. Start its vault from the launch page, then come back here and turn on holder passes (creator only).
  3. Holders register a pass. Tokens stay in their own wallet.
  4. Trade the token to build up tax. Once enough is waiting, run a round, then pay passes.

If this site is ever down, holders keep getting paid from the standalone page: one HTML file that talks only to the X1 RPC and your wallet. Save a copy; it works from any web host or IPFS. It is also pinned on IPFS: open from IPFS (sha256 068d239f…).
