For AI agents

An AI agent (Claude Code, or any agent that can run commands) can launch a token here for you. It follows this site's skill file and signs with a keypair on your own machine. The key is never sent anywhere: the site builds each transaction, and the agent signs it locally.

This page is for X1 {{NETWORK}} ({{SITE}}). Every command below uses this site; keep it for the whole launch, including a resume. Other network: mainnet (real funds) · testnet (test funds).

1. Tell your agent

Paste this into your agent, then answer its questions:

Read {{SITE}}/skill.md and follow it to launch a token for me on X1 {{NETWORK}} using {{SITE}}.

It checks your settings and the full cost first, and launches only after you say yes.

2. Or install it as a Claude Code skill

Then it loads by itself whenever you ask Claude to launch a token on X1:

mkdir -p ~/.claude/skills/x1-token-launchpad
curl -o ~/.claude/skills/x1-token-launchpad/SKILL.md {{SITE}}/skill.md

Other agents that read SKILL.md files can use the same file.

3. Or run it yourself, without an agent

curl -O {{SITE}}/agents/launch.mjs
npm i @solana/web3.js@1

Check: shows the settings, the full cost and your balances, and sends nothing.

node launch.mjs --site {{SITE}} --keypair wallet.json --name "My Token" --symbol MYT \
  --supply 1000000000 --tax 5 --pool 10 --lock forever

Launch: the same command plus --live, once you're happy with the check.

node launch.mjs --site {{SITE}} --keypair wallet.json --name "My Token" --symbol MYT \
  --supply 1000000000 --tax 5 --pool 10 --lock forever --live

Resume a launch that stopped, on the same site it started on:

node launch.mjs --site {{SITE}} --keypair wallet.json --resume <mint> --live

Your launches and how far each got:

node launch.mjs --site {{SITE}} --keypair wallet.json --status

Before signing anything, the launcher checks this site reports X1 {{NETWORK}}, and stops if it doesn't.

Before you launch

  • A launch can't be undone. The tax rate is fixed forever, and liquidity locked "forever" can never be withdrawn.
  • Never paste your private key or seed phrase into a chat. Give the agent the path to a keypair file on your machine instead.
  • Try it on testnet first: 99tax-testnet.vercel.app/agents. Free coins are on its faucet page.
